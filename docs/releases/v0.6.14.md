# 历史记录读取保护与报表修复

- 修复存储读取或 JSON 解析失败时，启动阶段可能用空默认值覆盖历史数据的风险。
- 为计时明细和报表汇总保存本地恢复副本；读取异常时尝试恢复，并提示用户。无法读取的原始内容会保留供排查。
- 保存失败时显示提示，不再让记录写入异常静默发生。
- 启动时校验报表汇总，使用仍存在的旧明细补齐遗漏，保留已超过明细保留上限的历史汇总，避免重复累计。
- 用户确认清空时同步清空恢复副本，避免主动清空后的记录再次出现。
- 新增旧版 21 条记录升级、损坏数据、临时读取失败、备份恢复、写入失败、清空及汇总修复测试。

已被旧版本覆盖或移除的数据不保证能自动找回。若升级后发现历史异常，请勿清空记录，应保留整个 WebView 数据目录以便恢复。
