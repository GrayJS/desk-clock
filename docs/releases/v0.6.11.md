# 番茄循环与界面优化

## 番茄循环

- 新增第三个“循环”标签页，原“记录”页顺延到第四个。
- 支持设置 1–99 轮，以及各 1–180 分钟的专注、休息时长，计划自动保存在本机。
- 按“专注 → 休息 → 下一轮专注”自动运行，最后一轮专注完成后停止，不追加休息。
- 支持暂停、继续和结束循环；每次专注完成照常写入记录、为成果树增加番茄。
- 普通计时器、迷你模式和托盘共享当前计时状态；迷你模式可查看循环进度并返回循环页。
- 每段计时沿用 Windows 通知偏好，退出应用会结束当前运行但保留循环计划。
- 倒计时改用截止时间计算，减少窗口隐藏或短暂卡顿造成的偏差。

## 同时包含 v0.6.10 的改进

- 清空专注记录前先弹出确认框，支持取消、Esc 和点击遮罩关闭。
- iOS 风格磨砂玻璃窗口与卡片；数字保持实心清晰，并增加轻微立体阴影和按钮按压反馈。
- 托盘新增“显示主界面”动作，并设为默认单击动作；“打开设置”仍可单独配置。
- 普通计时器的专注完成后保持专注模式，等待手动开始下一轮。
- 长休息和短休息合并为“休息”，原有短休息时长自动迁移。
- 标准窗口增高至 420×600，启动时恢复保存的尺寸档位。

## 更新方式

现有用户可在设置中检查更新，确认后静默下载安装；也可以下载本页的 Windows x64 安装包进行升级。已有本地记录与设置会保留。
