# 循环阶段可跳过，过程数据照常保留

- 循环页、普通计时器和迷你计时器新增“跳过专注 / 跳过休息”，可直接进入下一阶段。
- 跳过会保存阶段类型、计划时长、实际用时、时间与备注；历史记录明确标记“已跳过”。
- 循环进度区分处理轮数、已完成专注和跳过专注；跳过最后一轮专注后直接结束，不追加休息。
- 运行中跳过会继续下一阶段；暂停时跳过仍保持暂停。切换阶段时会取消旧通知，并按当前设置安排新通知。
- 跳过专注的实际用时计入今日专注时长，不增加完成轮数或番茄；跳过休息不会增加专注时长。
- 旧版专注记录及原有设置保持兼容，历史记录仍保留最近 200 条。

现有用户可在设置中检查更新，确认后静默升级；也可下载本页的 Windows x64 安装包。
