# 紧凑报表与专注月历

- 记录页升级为日、周、月、年报表，使用 Ant Design 与 Ant Design Charts / AntV。
- 月报使用日历，每日显示专注分钟数，颜色体现投入强度；点击日期可进入日报。
- 汇总专注时长、完成轮数、专注天数、跳过阶段与完成率，保留计时明细、备注和清空确认。
- 每日汇总独立保存，超过 200 条的旧明细淘汰后仍保留月／年统计。旧版本已移除的明细无法补回；清空会同步删除汇总。
- 标准窗口调整为 420×747，宽度不变；适配窄窗口、展开窗口和深浅主题，收紧留白，优先呈现核心统计。
- 报表按需加载，预览示例不会写入真实记录。

现有用户可在设置中检查更新，确认后静默升级；也可下载本页 Windows x64 安装包。
