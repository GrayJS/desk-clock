# 记录页报表与开发预览

记录页报表随 v0.6.13 发布；下述示例数据入口仅用于开发预览。

- “记录”页改为紧凑报表，支持日、周、月、年和指定日期；周从周一开始。
- 月报使用 Ant Design 日历，每格显示当天专注分钟数，颜色按当月投入强度分级；点击日期进入日报。
- 日、周、年使用 Ant Design Charts / AntV 柱状趋势图，附带可展开的数据表。
- 展示专注时长、完成轮数、专注天数、跳过阶段与专注完成率；保留计时明细、备注及清空确认。
- 标准窗口为 420×747；340 像素窄窗口纵向排列，720×520 展开窗口并排展示趋势与完成率。
- 报表、图表和控件按需加载，支持深浅主题。

## 统计与保留

完成专注按原有规则记入计划时长；跳过专注只计实际用时，跳过休息不计专注时长。
完成率为完成专注数除以完成专注数与跳过专注数之和，跳过休息不参与分母。
所有阶段按结束时间归入本机日期／小时。暂停不增加实际用时。

明细继续保留最近 200 条；新增 `morrow.reportArchive` 持续保存每日汇总，避免旧明细淘汰后丢失月／年报数据。
首次升级从仍存在的明细初始化，旧版已经移除的记录无法恢复。
清空确认会同时清除明细和汇总。记录内容和报表不会上传。

## 本地预览

运行 `npm run dev`，打开 `http://127.0.0.1:1420/?preview=reports&theme=light&period=month`。
这是仅开发环境可用的示例数据预览，示例记录不会写入真实历史。
`theme=dark` 查看深色；`period` 可设为 `day`、`week`、`month`、`year`。

`npm test` 包含 18 项测试，覆盖循环、旧记录兼容、跳过统计、跨年周、闰月、夏令时、周期导航与超过 200 条后的汇总保留。
